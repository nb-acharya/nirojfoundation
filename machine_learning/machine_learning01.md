## MACHINE LEARNING

- part of artificial intelligence
- computer learn from the data instead of writing strict rules for every step
- training a piece of software called model


## types of machine learning
- supervised learning
- unsupervised learning
- reinforcement learning
- semi supervised learning


## Topics necessary for ML
- linear algebra: vectors, matrices, matrix multiplication, dot product, eigenvalues
- probablity: mean, variance, standard deviation, conditional probability, bayes theorem
- statistics: hypothesis testing, pvalue, correlation, distribution
- calculus:derivatives, gradient, gradient descent

## supervised learning:
models train on labeled data, consisting of input output pairs

- data, model, training, evaluating, inference
- more features and more data is needed to train the model
- just because there are many features that doesnt mean the features have predictive powers

example: classification and regression

- regression measures the numeric value, eg: house price prediction
- classification measures in which category does the label incline to: eg: spam email predictor,
