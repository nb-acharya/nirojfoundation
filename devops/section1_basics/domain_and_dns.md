### domain
- a domain name is the human readable address of a website
- branding, professionalism, Trust
- Domain registrars: Godaddy, bluehost, aws route 53(for advanced users)

## domain name system
- dns is used to link the domain name with the ip address
- DNS resolution process: users enters website ---> check cache ---> ask dns resolver ---> go to root server ---> go to TLD server

### DNS record types
- A Record: domain to ipv4 address
- AAAA Record: domain to ipv6 address
- CNAME record: alias for another name
- MX record: directs email to mail server
- TXT record: hold text for verification and additional info
