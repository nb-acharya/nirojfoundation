### ssh secure shell
It is a secure protocol for communicating with another computer over the internet

###### core problem: your computer needs to prove who it is to Github

there are two common ways to prove your identity:
1. https: you login with a username and a token(like a pasword)
2. ssh: you use a cryptographic key pair instead of a password

#### how ssh works?
you generate a key pair: 
a private key: stays secret, lives only on your computer in ~/ssh/
a public key: safe to share, you upload it to github

These two keys are mathematically linked, but you cant derive the private key from the public one.

### Test your SSh connection
ssh -T git@github.com


### whole process in ssh:

to check the ssh key: ls ~/.ssh

## if you dont have an SSH key:
```
ssh-keygen -t ed25519 -C "your_email@example.com"
```
Just press enter for all prompts

## ~/.ssh/
id_ed25519  ---> your private key (keep secret)
id_ed25519.pub ---> your public key (shared with github)
known_hosts ---> list of trusted SSH servers

## SSH agent
SSH has a helper called the SSH agent.

- Start the SSH agent
```
eval "$(ssh-agent -s)"
```

- Add your SSH key to the agent
```
ssh-add ~/.ssh/id_ed25519
```


#### display your public key
```
cat ~/.ssh/id_ed25519.pub
```

## final steps
Copy the entire line (from ssh-ed25519 all the way to your email at the end).
