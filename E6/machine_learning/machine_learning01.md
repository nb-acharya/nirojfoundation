## MACHINE LEARNING

- part of artificial intelligence
- computer learn from the data instead of writing strict rules for every step


## types of machine learning
- supervised learning
- unsupervised learning
- reinforcement learning
- semi supervised learning


## Topics necessary for ML
- linear algebra: vectors, matrices, matrix multiplication, dot product, eigenvalues
- probablity: mean, variance, standard deviation, conditional probability, bayes theorem
- statistics: hypothesis testing, pvalue, correlation, distribution
- calculus:derivatives, gradient, gradient descent
